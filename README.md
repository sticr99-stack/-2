# اليماني تك | منصة خدمات السفر

واجهة عربية وإنجليزية لاستكشاف خدمات السفر وإنشاء طلب مبدئي وحفظ ملخصه بصيغة PDF.

## ما هو جاهز

- البحث التوضيحي عن الرحلات والفنادق وخدمات التأشيرات والتأمين وشرائح eSIM.
- إنشاء طلب مبدئي وحفظ ملخص PDF.
- تبديل اللغة والعملة، وعرض الطلبات المحفوظة في الجلسة.
- صفحة تعريف وخصوصية وشروط، مع أماكن مخصصة لإضافة بيانات التواصل والحسابات الاجتماعية لاحقًا.
- إعداد Render وفحص صحة الخدمة عبر `/api/health`.

## حدود النسخة الحالية

هذه نسخة معاينة. لا تنفّذ حجزًا مؤكدًا أو دفعًا، ولا تتصل بمزوّدي الطيران أو الفنادق أو التأشيرات أو التأمين أو eSIM. النتائج والأسعار توضيحية، وملف PDF ملخص طلب مبدئي فقط.

## التشغيل على الجهاز

1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. شغّل `npm start`.
4. افتح `http://localhost:3000` في المتصفح.

## إعداد المعاينة على Render

ملف `render.yaml` يعرّف خدمة الويب وأمر التشغيل وفحص الصحة. بعد رفع ملفات هذا المجلد إلى مستودع GitHub، اربط المستودع بحساب Render واختر إنشاء خدمة من Blueprint. راجع الإعدادات ثم ابدأ النشر من لوحة Render.

بعد النشر، افتح `https://رابط-الخدمة/api/health` وتأكد أن `bookingMode` يساوي `demo_only`.

راجع [دليل النشر بالعربية](DEPLOYMENT_AR.md) لمزيد من التفاصيل. لا تضع مفاتيح API أو أسرارًا في ملفات الواجهة أو المستودع؛ تُحفظ أسرار المزوّدين كمتغيرات بيئة في الخادم بعد اختيارهم.
